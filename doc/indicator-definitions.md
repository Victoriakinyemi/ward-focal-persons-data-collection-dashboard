# Indicator Definitions

## Treatment coverage
This is calculated as (Treated children / Eligible children) per ward.

Target for current round (third) is 80% (0.80). Flag wards below this value.

## Coverage Target Updates
At the start of each campaign round, this document is reviewed and updated with the round's coverage target (as seen above for the third round). The `coverage_target` value in config.json must be updated to match. Data team members updating the dashboard must always ensure to confirm the currently implementing round's target in this document before editing config.json, and should not change the target without a corresponding update to this section.
